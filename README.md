# Amazon Style Image Zoom Effect

This project is an Amazon-style product image gallery with zoom functionality built using HTML, CSS, and JavaScript.

Users can:
- Hover over small product images to change the main image
- Zoom into the product image on mouse hover
- View dynamic zoom movement based on cursor position

## Features

- Product Image Gallery
- Hover Image Preview
- Image Zoom Effect
- Dynamic Background Positioning
- Clean UI Design
- Pure HTML, CSS, and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
